# 배움의 궤도 · 주간 학습 플래너

DSU AI 챌린지 A트랙용 학습 관리 MVP입니다. Python 3.12와 Streamlit을 사용하며 회원가입, 데이터베이스, 외부 AI API는 사용하지 않습니다. **현재는 규칙 기반 프로그램이며 실제 AI 분석 기능은 없습니다.** 모든 입력과 결과는 세션 메모리에만 보관됩니다.

## 설치와 실행

Python 3.12 권장. 이 저장소 디렉터리에서 실행합니다.

```bash
python -m venv .venv
# macOS / Linux
source .venv/bin/activate
# Windows PowerShell에서는 위 명령 대신 .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

터미널에 표시되는 주소를 브라우저로 엽니다. 종료는 Ctrl+C입니다. 클라우드에는 `/workspace/.venv`에 의존성을 설치했습니다. 해당 환경에서는 `/workspace/-`에서 `/workspace/.venv/bin/python -m streamlit run app.py`로 실행할 수 있습니다.

필수 라이브러리는 `streamlit`(화면·입력·세션 관리), `pandas`(표 데이터)입니다. `datetime`, `math`, `unittest` 등은 Python 기본 라이브러리입니다. API 키나 별도 서비스는 필요하지 않습니다.

## 네 화면 시연·캡처 순서

상단의 화면 선택으로 이동합니다. 예시 날짜는 한국 시간 기준 이번 또는 다음 월요일에 맞춰 생성됩니다. 시작일은 어떤 요일이든 선택할 수 있고 그날부터 7일을 계획합니다.

1. **목표·일정 입력**: 가상 예시가 채워져 있습니다. 목표 문장, 목표 날짜, 학습 항목·시간·중요도·마감일·목표 관련 여부와 날짜별 가용 시간을 편집한 후 캡처합니다. 표 아래 빈 행으로 추가, 행 선택으로 삭제할 수 있습니다. `주간 학습 계획 생성`을 누릅니다.
2. **초기 학습 계획**: 일별 배정, 이번 주 목표량, 이월량을 확인하고 캡처합니다. 초기 계획은 이후 비교를 위해 고정 보관합니다.
3. **학습 일정 변경**: 첫날 가능 시간을 2→0시간으로 변경합니다. 새 항목에 `긴급 발표 준비`, 3시간, 중요도 5, 이번 주 마감일을 넣고 `새 일정 추가 및 자동 재계획`을 누릅니다. 변경 화면을 캡처합니다. 가능 시간 변경은 즉시 반영되고, 새 일정은 추가 버튼을 눌러야 반영됩니다.
4. **수정 계획·변경 이유**: 기존·수정 시간 비교, 항목별 변경 이유, 수정된 날짜별 계획, 다음 주 재검토량을 캡처합니다. 화면이 길면 브라우저 전체 페이지 캡처를 사용합니다.

1번 화면에서 다시 생성하면 초기 계획과 변경 기록을 새 입력으로 대체합니다. 1번 화면의 미제출 편집값은 기존 결과에 반영되지 않습니다. 페이지 새로고침이나 세션 종료 시 데이터가 사라질 수 있습니다.

## 코드 구조와 핵심 함수

```text
app.py                 네 화면, 예시 데이터, 입력 검증, 세션 상태
planner.py             주간 계획과 비교를 계산하는 순수 Python 함수
requirements.txt       설치할 라이브러리 버전
 tests/
  test_planner.py      배정·마감·우선순위·이월량 계산 테스트
  test_app.py          네 화면 이동과 실제 위젯 조작 테스트
```

- `make_plan(tasks, capacities, start, target)`: 항목을 우선순위순으로 정렬하고 날짜별 남은 시간에 배정해 결과 딕셔너리를 반환합니다. 화면 코드와 분리되어 단독 테스트할 수 있습니다.
- `compare_plans(before, after)`: 항목 ID를 기준으로 시간 증감과 날짜 이동을 비교하고 계산에 근거한 한국어 설명을 만듭니다. 같은 이름의 항목도 입력 순서의 ID로 구별합니다.
- `read_tasks()`: 편집 표를 계산 함수가 받는 딕셔너리 목록으로 변환합니다.
- `capacity_inputs()`: 7일의 가능 시간을 입력받습니다.
- `show_plan()`: 합계, 날짜별 계획, 항목별 잔량과 마감 위험을 표시합니다.
- `st.session_state`: 초기 계획, 수정 계획, 추가한 항목을 페이지 이동 사이에 보관합니다.

입력 → `read_tasks` → `make_plan` → 세션 보관 → `show_plan` 순서로 동작합니다. 변경 시 원본을 덮어쓰지 않고 `make_plan`을 다시 호출한 뒤 `compare_plans`로 차이를 설명합니다.

## 배정 규칙과 범위

시간은 30분 단위이며 하루 0~24시간을 허용합니다. `필요 시간`은 전체 남은 학습량입니다.

1. 목표 관련 학습의 유효 마감일은 학습 마감과 목표 날짜 중 빠른 날입니다. 그때까지의 남은 주 수(올림)로 필요 시간을 나누고 30분 단위로 올려 이번 주 목표량을 정합니다. 목표와 무관한 항목은 전체 필요 시간을 이번 주 수요로 봅니다.
2. 유효 마감이 계획 시작일 기준 7일 미만이면 100점(이미 지난 항목 포함), 14일 미만이면 30점입니다. 중요도 × 10점, 목표 관련 항목 15점을 더합니다. 점수가 높은 순, 동점이면 마감일 순, 그다음 입력 순입니다.
3. 각 항목을 가능한 가장 이른 날짜부터 배정합니다. 날짜별 가용 시간을 차감하므로 시간을 초과하지 않습니다. 마감일 당일까지 배정 가능하고 마감 이후에는 배정하지 않습니다. 지난 마감 항목은 배정 없이 위험 안내와 미배정량을 표시합니다.
4. `다음 주 재검토`는 이번 주 목표 중 시간 부족으로 배정하지 못한 양입니다. `장기 분산 잔량`은 처음부터 이후 주로 나눈 양입니다. **전체 필요량 = 배정량 + 다음 주 재검토량 + 장기 분산 잔량**입니다. 마감이 지난 미배정량은 다음 주로 미룬다고 마감이 충족되지 않으며 별도 대응이 필요합니다.

설명 생성에는 AI API나 언어 모델을 사용하지 않습니다. 목표 문장은 표시용이며 의미를 자동 해석하지 않고 사용자의 `장기 목표 관련` 체크와 날짜를 계산에 반영합니다. 우선순위 기반의 단순한 탐욕 알고리즘으로 전역 최적해를 보장하지 않습니다. 시간대별 충돌, 학습 완료 기록, 자동 차주 달력 생성은 구현 범위에 포함하지 않습니다.

## 테스트

저장소 디렉터리에서 실행합니다. 테스트 전용 추가 패키지는 필요하지 않습니다.

```bash
python -m unittest discover -s tests -v
```

계산 테스트는 시간 초과 방지, 마감 전 배정, 중요도·긴급도, 목표 날짜에 따른 주간 분산량, 0시간·지난 마감, 재계획 비교, 입력 검증, 총량 보존을 확인합니다. Streamlit `AppTest`는 실제 앱 스크립트를 실행하며 계획 생성 버튼, 네 화면 전환, 가능 시간 변경, 새 일정 추가, 비교 결과, 초기 계획 보존과 잘못된 입력 안내를 확인합니다. 브라우저 픽셀 디자인을 검증하는 테스트는 아닙니다.
